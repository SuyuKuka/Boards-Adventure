Format pour les JSON : 
Paramètres générals absoluments nécessaire :
    "id" <- numéro de la case (0 pour le start)
    "type" <- type de la case ("Kingdom", "Property", "Start", "CHANCE", "CHEST" ou "SPECIAL")
    "xPos" <- position x du centre de la cellule sur le fichier png
    "yPos" <- position y du centre de la cellule sur le fichier png

Paramètres pour les PROPRIETES :
    "group" <- groupe de la propriété (même couleur = même groupe).

Autres paramètres :
    "value" <- montant à manipuler (prix d'achat pour une propriété, gain pour le start,...) {0 par défaut si non spécifié}

Un exemple de fichier cells.json : 

[
	{
		"id" : 0,
		"type" : "START",
		"value" : 200,
		"xPos" : 0,
		"yPos" : 0
	},
	{
		"id" : 1,
		"type" : "PROPERTY",
		"value" : 100,
		"xPos" : 0,
		"yPos" : 0
	},
	{
		"id" : 2,
		"type" : "SPECIAL",
		"value" : 200,
		"xPos" : 0,
		"yPos" : 0
	}
]
